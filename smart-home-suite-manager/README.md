# Smart Home Suite Manager 1.11.0

Smart Home Suite 1.11.0 es un **PRE-RELEASE** basado en la línea estable 1.10.0.

Actualiza Smart Automations a **1.3.0** con Alert Control runtime V1.0.0 para Consumo elevado y Límite de kWh.

Acciones disponibles:

- `install_repair`
- `validate_only`
- `restore_latest`

No cambia la estructura de instalación, backup, staging, rollback ni aislamiento de módulos.
