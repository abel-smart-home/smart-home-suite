# Smart Home Suite Manager 1.1.1

Instala, actualiza, valida, repara y restaura Smart Home Suite en Home Assistant OS sin HACS.

Acciones disponibles:

- `install_repair`
- `validate_only`
- `restore_latest`

Smart Home Suite 1.1.1 mantiene **Smart Automations 1.0.0** como quinto módulo oficial, corrige la estabilidad del selector MDI de Smart Home y conserva staging, backup verificado, validación posterior y rollback automático.
